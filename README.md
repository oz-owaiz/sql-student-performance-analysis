# Student Performance Analysis – SQL Project

## Project Overview

This project focuses on analyzing student academic performance using SQL and MySQL Workbench.

The objective is to practice SQL queries to retrieve, filter, organize, and analyze student records and identify useful insights from academic data.

## Dataset

The dataset contains 20 student records with the following columns:

- StudentID
- Name
- Age
- Gender
- City
- Subject
- Marks
- Attendance

## Tools Used

- MySQL
- MySQL Workbench
- CSV Dataset

## SQL Concepts Practiced

**Basic SQL**
- SELECT
- WHERE
- DISTINCT
- ORDER BY
- LIMIT

**Aggregate Functions**
- COUNT()
- AVG()
- MIN()
- MAX()

**Grouping and Filtering**
- GROUP BY
- HAVING

**Intermediate SQL**
- Subqueries
- Correlated Subqueries
- CASE WHEN

## Business Questions Answered

1. Display all student records.
2. Identify students scoring above 80.
3. Find the highest and lowest marks.
4. Calculate average marks.
5. Analyze average marks by subject.
6. Count students by city.
7. Analyze average marks by gender.
8. Identify subjects with average marks above 75.
9. Find students performing above the overall average.
10. Identify the highest-scoring student in each subject.
11. Categorize students into grades based on marks.
12. Identify students with attendance below 75%.

Additional exercises involving filtering, sorting, counting, and grouping were also completed.
